# ¡Che, Bicho!

Una aventura gaucha. Prototipo v1.0. By J. Pepe.

Juego de captura y combate de bichos ambientado en el norte argentino: Salta, Corrientes y Jujuy.

**Jugar:** https://jonleopepe.github.io/che-bicho/ (celular o PC; se puede agregar a la pantalla de inicio).

## Para desarrollar
- `npm test`: pruebas del núcleo.
- `npm run arte`: regenera el arte del juego desde los catálogos de diseño (`arte/fuente`).
- Probar en la PC: `python3 -m http.server` en esta carpeta y abrir http://localhost:8000

Fuentes con licencia libre: ver `fuentes/LICENCIAS.txt`.
